# Canvas API

This markdown file attempts to document the Slack canvas API.

## Relevant values

- `U09T3PJB3RC`: Slack user ID
- `E09SQBSDN5V`: Slack enterprise ID
- `ETf9EARnapN`: Canvas collab user ID (returned in Init response)
- `AdB9cAkIJKc`: User / client / session identifier?
- `temp:A:UWL12c3a26568ba30840b53c0372e7a92a4`: Client-generated temporary QUIP thread ID, must start with `temp:A:UWL` followed by 32 random hex digits
- `temp:B9214e00bb136f7da353653ac28231014`: Client-generated temporary QUIP document ID, doesn't seem to require any particular format
- `UWL9AACEeHP`: QUIP thread ID
- `UWL9BAKSlxp`: QUIP document ID

token=xoxc-...
